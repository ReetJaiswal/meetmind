# MeetMind

MeetMind is an AI-powered meeting intelligence platform that transcribes meeting audio and automatically generates summaries, key decisions, and actionable tasks.

## Tech Stack

- React + Vite
- FastAPI
- Faster Whisper (local speech recognition)
- Ollama (Qwen3:4b)
- SQLite

## Features

- Upload meeting audio
- Local speech-to-text transcription
- AI-generated executive summaries
- Key decision extraction
- Action item extraction
- Owner and deadline detection
- Meeting history

## Architecture

Audio Upload
→ Faster Whisper
→ Transcript
→ Ollama (Qwen3:4b)
→ Structured Meeting Insights
